# Duke homepage game center — 2026-11-17

Owner request: live game stats should be on the Duke homepage. Both `/sports/duke-basketball/` and `/sports/duke-football/` now place a game center above their existing content tabs. It is visible on the default Highlights view and persists when tabs change. Existing season statistics remain in the Stats tab.

The shared client reads ESPN's public daily scoreboard for the Eastern calendar date, selects only a Duke (team 150) event, and reads the matching event summary. Live events take priority, followed by pregame and the latest final in that day's feed. Scores, status, team comparisons and Duke player groups come from that summary. Missing measurements show an em dash or a clear not-reported message. No hardcoded game ID, simulated plays, preview override or guessed score is used. Pregame scores are hidden. Game date and successful-update time display in ET.

Polling is 10 seconds during live games and 60 seconds otherwise; hidden pages skip requests and refresh on visibility return. Requests have timeouts, unmount aborts them, and polling does not overlap. On feed failure, the last successful snapshot is explicitly flagged as potentially out of date and loses its LIVE treatment. A new event clears the old event before fetching its summary. No-game and initial-loading states are explicit. The hero LIVE badge now uses this same actual feed rather than a time-based assumption; its redundant score ticker is replaced by the full panel.

Validation: four dependency-free parser/selection tests (`node --test scripts/test-duke-game-stats.mjs`, Node 24) pass: Duke selection, team/stat identity despite ordering, missing values and absent players, alternate score shapes, final state, mismatched-event rejection and malformed inputs. All four changed TS/TSX files pass ESLint. Web TypeScript and full 5,642-page production export pass. A recorded ESPN basketball summary parsed 25 team measurements and 13 Duke player rows. Render assertions cover final, stale and no-game displays. Recorded QA files remain ignored/local and are not source or deployment assets.
