# Work Sans

Unmodified variable font from Google's official Fonts repository, retrieved November 17, 2026.

Source: https://github.com/google/fonts/blob/main/ofl/worksans/WorkSans%5Bwght%5D.ttf
License: WorkSans-OFL.txt (SIL Open Font License 1.1), retained from the same directory.
SHA-256: f50f61f2ba738e239442d40bf1069adb195c224b6a5a73a581fc2f3ed62a9f63

The full font preserves Latin, extended Latin and Vietnamese coverage. Variable weight axis: [{"tag":"wght","min":100,"max":900}].
Used by the All Day & Night page through next/font/local to avoid the Google Fonts extensionless-URL build failure. No font package is installed.
